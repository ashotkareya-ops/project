# Центр поддержки бизнеса

Веб-платформа, которая помогает малому и среднему бизнесу находить меры государственной поддержки, разбираться с налогами и отчётностью и получать консультации с помощью ИИ-бота.

Учебный проект: разработка и оценка IT-проектов.

## О проекте

**Тема:** Центр поддержки бизнеса — сопровождение предпринимателей по грантам, налогам и отчётности.

**Цель проекта:** малый бизнес часто не знает о доступных грантах и субсидиях, путается в налогах и не может позволить себе штатного юриста и бухгалтера. Проект собирает меры поддержки и консультации в одном месте, чтобы предприниматели получали помощь быстрее и дешевле.

**Цель учебной работы:** придумать 3 идеи, оценить их по критериям, выбрать победителя и описать концепцию.

**Победившая идея:** Центр поддержки бизнеса (нормированная оценка 4.23 из 5).

## Целевая аудитория

МСП, ИП, стартапы и самозанятые. Основной рынок: Россия, затем страны СНГ.

## Ключевые функции

- Подбор грантов и субсидий под профиль бизнеса
- Помощь в подготовке заявок
- Консультации по налогам и отчётности
- ИИ-бот для сопровождения в ФНС и центрах «Мой бизнес»
- Личный кабинет и шаблоны документов (планируется во втором релизе)

## Технологии

React, Python (Django)
